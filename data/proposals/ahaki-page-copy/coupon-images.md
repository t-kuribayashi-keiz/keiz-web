### No.11 カウンセリング画像をChatGPTで作るときのプロンプト

`funiki_02_josei-shinkyushi.png`(雰囲気②で使っている、紺のスクラブの女性スタッフ画像)を
**見本として一緒に添付**し、人物・制服・内装のトーンを揃える。

```
添付した画像は、この鍼灸接骨院で実際に使っているスタッフ写真です。この画像と同じ人物・
同じ制服(紺色のスクラブ+黒の長袖インナー)・同じ雰囲気の院内で、カウンセリングの
シーンの写真を作ってください。

・女性スタッフが、椅子に座ったお客様(顔は写らない角度)の話を聞いている場面
・スタッフは体をお客様の方に向け、穏やかに微笑んでいる
・手元にカルテかタブレットを持っていてもよい
・院内は明るく清潔で、木目調の落ち着いた内装
・文字・ロゴ・透かしは入れないでください
・横長(4:3)で作ってください
```

### No.9 の制服を紺に直すときのプロンプト

`ai_zuhi-lift.png` を添付して使う。

```
添付した写真の、施術者が着ているエンジ色(ワインレッド)の制服を、濃い紺色(ネイビー)に
変えてください。

・変えるのは制服の色だけです。施術者の手、お客様の肌や髪、鍼、タオル、背景など、
  他の部分は一切変更しないでください
・色は、医療用スクラブによくある落ち着いた濃紺にしてください
・布のシワや陰影はそのまま残し、自然に見えるようにしてください
・写真の構図・明るさ・色調も変えないでください
```

## 注意点

- **`coupon_04_youtsu.jpg` は元が548×535pxと小さい**(スマホ撮影と思われる)。クーポンの
  サムネイル表示なら足りるはずだが、粗く見えるようなら差し替えを検討する。
  代替候補は `その他/IMG_1904.JPG`(706×665px、同じく腰部だが手の置き方がやや不自然)。
  **腰部のカットはこの2枚しか無い**ので、今後の撮影で腰の施術カットを増やしておくとよい。
- 4枚とも施術者の制服にエンジ色は写っていないため、紺への色替えは不要
  (`coupon_04_youtsu.jpg` の施術者は元から紺)。
- No.1・No.3・No.7・No.8には既に画像が入っている。**同じ写真を重複させないよう、
  設定前に既存4件が何の写真かを確認すること。**
