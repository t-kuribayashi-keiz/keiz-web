## 各院ファイルの読み方

各ファイルは以下の構成。上から順に人間がコピペ/画像生成すれば完成する。

1. **トップメインコピー/サブコピー** — SalonBoardの「キャッチコピー」欄にそのまま貼る文字数で作成済み
2. **トップ画像(2枚)** — ①ロゴ風バナー(施術写真+テキスト)②施術クローズアップ。それぞれ
   ChatGPT Image 2.0等に貼る生成プロンプトと、バナーへの文字入れ指示(Canva等で重ねる用)を用意
3. **フォトギャラリー(10枚)** — タイトル・ハッシュタグ・画像生成プロンプトを1枚ずつ用意
4. **クーポン(9本: 新規7+再来2)** — 名称・価格(元値→初回価格)・説明文・付与ジャンルタグ
5. **サロンからの一言**
6. **ジャンル設定チェック** — SalonBoard「掲載管理」→「基本情報」→「ジャンル」で、リラクゼーション/
   整体・カイロだけでなく**エステ・フェイシャル系ジャンルにもチェックが入っているか**必ず確認する
   (表示名はSalonBoard側の実際の文言に読み替える)。ここが漏れていると閲覧機会そのものを失う、
   というのが今回のブラッシュアップで最優先・即効性ありとされた項目
7. **SEOキーワード** — 店舗情報のフリーワード欄に入れる語

## 画像方針: 実際の店舗写真とAI生成の使い分け(2026-09-10、方針修正)

栗林さんの指摘により方針を修正した: 参考2院のトップ画像はどちらも価格・キャッチコピー・
店名が写真に直接デザインされたバナーであり、単なる素材写真ではなかった。また、AI生成の
架空の内装・架空のスタッフを使うと、**実際の店舗(制服・内装・雰囲気)と食い違い、来店時に
利用者へ違和感を与える**という問題がある。そのため画像は用途によって使い分ける:

**実際の店舗写真を必ず使う(AI生成不可)**:
- トップ画像(キャッチコピー横のバナー) — 店舗の第一印象を作る場所であり、参考2院のように
  価格・店名テキストを写真に直接デザインして見せる必要がある
- 院内・ベッド周りを見せるカット(こだわり③等) — 実際の店内の様子そのものが情報
- スタッフ紹介の写真 — 実在の人物を名乗るコーナーなので、架空人物を実在スタッフとして
  掲載すると利用者に誤解を与える

**AI生成でよい(顔・手元だけのクローズアップに限る)**:
- 美容鍼(顔)施術クローズアップ、頭皮鍼・全身鍼施術、施術者の手元(鍼を持つ手)、
  施術後の美肌イメージ等、店舗の内装・制服が写り込まない構図のもの
- ただし**構図を広げて院内全体や制服が写るようにはしない**(その場合は実写に切り替える)
- 全プロンプトは「実在の人物ではないモデル」「テキスト無し」「透かし無し」を明記している。
  ChatGPT Image 2.0やその他の画像生成AIにそのまま貼り付ける
- アンビション森本さん談: AI生成写真は**「AIっぽすぎなければ」問題ない**。不自然な指の本数や
  肌の質感が出た場合は同じプロンプトで再生成し、一番自然なものを選ぶこと

**トップ画像のテキスト合成**: AIで人物・施術写真だけ生成する場合も含め、指定のテキストは
**Canva等で別途重ねる**(AI画像生成は日本語テキストの描画精度が低いため、テキストは
画像生成後に人力で載せる方が確実)。

**柔整(整骨)を連想させる写真・院内什器(骨盤矯正ベッド等)は一切写り込ませない**。
全カット「美容鍼灸サロン」に見える構図・トーンで統一する。

**ケイズグループのブランドカラー・ロゴが手元にある場合**は、上記の仮の配色(ベージュ/紫系)
より優先して使うこと。

## 店舗基本情報の出典

各院ファイルの「店舗基本情報」ブロックは`data/clinics.json`(院マスタ)の実データを転記した
もの。2026-09-10、初版のコピーがこれを反映しておらず、**新静岡駅前鍼灸接骨院を「土日祝日も
営業」と誤記していた(実際は日曜定休)**ため修正済み。他ブランド・他院向けに複製する際は、
必ず`data/clinics.json`の該当院を確認してから営業日・住所・建物名をコピーに反映すること。

## 価格設計の考え方

5院共通のクーポン価格帯は、本八幡南口で実際に運用中だった価格(美容鍼¥4,500・全身鍼¥3,000)と
今回参考にした2院の相場(¥3,000〜¥6,400、元値からの半額弱訴求)を踏まえて統一設計した。
**割引率・実際の原価は各院の判断で調整可**。ここに書いた数字はそのまま使える叩き台として提示する。
