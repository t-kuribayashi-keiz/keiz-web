# ローカルセッション向け指示: 本八幡南口「雰囲気・メニューなど」3枠の差し替え

対象: **本八幡南口鍼灸接骨院(あはき柔整プラン側)のみ**。他4院はこのセッションでは触らない。

## やること

SalonBoardの「サロンの雰囲気・メニューなど」3枠を、完成したバナー画像3枚に差し替え、
タイトルと説明文を設定して反映申請まで行う。

## 使う画像(リポジトリ内)

`data/proposals/ahaki-page-copy/generated-images/funiki/` 配下。いずれも 1448×1086 の横長。

| 枠 | ファイル | 画像内の見出し |
|---|---|---|
| 1 | `funiki_01_kokka-shikaku.png` | 国家資格者が施術します / はり師・柔道整復師 |
| 2 | `funiki_02_josei-shinkyushi.png` | 女性鍼灸師が在籍しています |
| 3 | `funiki_03_otameshi-1480.png` | 気軽にお試しいただけます / 全身鍼 ¥4,950→¥1,480 |

## 設定するタイトル・説明文

SalonBoardの入力欄の文字数上限に引っかかった場合は、**意味を変えずに短くしてよい**
(上限値が分かったら実装ログに残すこと)。

### 1枠目

```
タイトル
国家資格者が施術します
```

```
説明文
はり師・柔道整復師などの国家資格を持つ施術者が、お身体の状態を確認しながら一人ひとりに
合わせて鍼灸施術を行います。鍼がはじめての方もご安心ください。
```

### 2枠目

```
タイトル
女性鍼灸師が在籍しています
```

```
説明文
女性の鍼灸師が在籍しております。肩こり・腰痛のご相談はもちろん、美容鍼についても
女性のお客様に安心してお話しいただける環境をご用意しています。
```

### 3枠目

```
タイトル
気軽にお試しいただけます
```

```
説明文
全身鍼(肩こり・腰痛)を初回¥1,480でご用意しています。鍼をはじめて受ける方も、
まずはお気軽にお試しください。
```

## 着手前に必ず確認すること

**2枠目「女性鍼灸師が在籍しています」は、本八幡南口に女性の鍼灸有資格者が実際に在籍して
いる場合のみ設定する。** 在籍していないのに掲載すると虚偽表示になる。

確認方法は Skill [`shinkyu-staff-check`](../../../.claude/skills/shinkyu-staff-check/SKILL.md)
の手順(ブラウザで「◇スタッフ写真一覧」を開き、本八幡南口のブロックで資格が `鍼灸師` /
`柔整・鍼灸` の人を探し、顔写真で女性かどうかを見る)。

- 在籍が確認できた → 2枠目も設定する。あわせて `data/staff-shinkyu-roster.md` の
  本八幡南口の行を確認結果で更新する
- 確認できない / 判断が付かない → **2枠目は保留**し、1枠目と3枠目だけ設定して、
  栗林さんに確認を依頼する

## 手順

1. 上記の在籍確認を先に済ませる
2. SalonBoardにログインし、本八幡南口鍼灸接骨院(あはき柔整プラン側)の掲載管理を開く
3. 「サロンの雰囲気・メニューなど」欄を開く。**現在1枠目に`鍼治療 (1).jpg`、2枠目に
   `美容鍼 (6).JPG`が実写のまま設定されている**ので、これを上記のバナー画像に差し替える。
   3枠目は未設定なので新規登録
4. 各枠にタイトル・説明文を入力
5. 反映申請まで行う
6. 実装ログを `data/proposals/ahaki-page-copy/01_本八幡南口鍼灸接骨院.md` の末尾に追記し、
   ブランチ `claude/learnings-bulk-import-k9y35q` にコミット・プッシュ

## 注意

- **この作業以外に手を出さないこと。** キャッチコピー、クーポン、フォトギャラリー、
  スタッフ紹介、こだわり条件などは今回の対象外
- 他のセッションが同じChrome・同じアカウントで動いていると、タブが数十秒固まることが
  過去に2回起きている(`01_本八幡南口鍼灸接骨院.md`の実装ログ参照)。固まったら
  他セッションの作業が終わるのを待つ
- 画像は5院共通で使い回せる作りにしてあるが、**今回は本八幡南口だけに適用する**

## 申し送り(栗林さんへ確認が必要な点)

2枠目の画像に写っている女性は、**手元の実写素材フォルダ
(`data/brand-assets/shinkyu-photos/`)には無いカット**で、AI生成の可能性が高い。
紺色のスクラブという制服も、実際のケイズグループの制服(黒の長袖+エンジ色)とは
異なって見える。栗林さんは以前「制服も内観もテキトーになってしまうのは困る」と
指摘していたため、**このまま掲載してよいかを確認してから反映する**のが望ましい。
