# ローカルセッション向け指示: ブラッシュアップ効果の測定(サロンレポート)

対象: **本八幡南口鍼灸接骨院(あはき柔整プラン側)**。まずこの1院で見る。

## やること

SalonBoardの 分析 →「HOT PEPPER Beautyレポート」→ サロンレポート から、**日次の
サロン情報PV数・予約数**を取得し、ブラッシュアップ前後で比較する。

画面の入口: 分析メニューの「基本情報」を開き、サマリ/PV数のグラフ下にある
**「その他のデータを確認したい場合はサロンレポートをご利用下さい」**のリンクから
サロンレポートへ進む。CSV出力があればCSVで取得する(日次が取れる形式を優先)。

## 取得する期間

**2026-08-01 〜 2026-09-17 の日次**。比較区間だけでなく8月分も取るのは、
もともとの日々のブレ幅(ベースライン)を知らないと差が誤差かどうか判断できないため。

## 比較のしかた

### 反映は1回ではなく段階的に行われている(重要)

栗林さんは「9/10くらいにブラッシュアップ」と認識しているが、実装ログ上の本番反映は
次の2段階に分かれている。**9/10で単純に線を引くと解釈を誤る。**

| 時期 | 反映内容 |
|---|---|
| **9/11〜9/12** | TOP画像3枚、サブコピー、こだわり3項目、SEOキーワード、フォトギャラリー刷新、雰囲気・メニューなど3枠 |
| **9/17〜9/18** | 特集4件の画像、クーポン画像7件 |

したがって今回測れるのは**第1段階(9/11〜12)の効果だけ**。第2段階は反映直後なので
数字にはまだ現れない。

### 比較区間

第1段階の前後で、**曜日構成を揃えた7日間**で比較する。

- **前**: 2026-09-04(金)〜 2026-09-10(木)
- **後**: 2026-09-11(金)〜 2026-09-17(木)

曜日が完全に一致するので、曜日差の影響を受けない。

### 見るべき指標と優先順位

1. **サロン情報PV数** … 今回の施策(TOP画像・写真・特集)が直接効くのはここ。**主指標**
2. **予約数** … 最終成果だが、この院は月10件前後の規模。7日では数件しか動かず、
   差が出ても誤差の範囲になりやすい。**参考指標として見る**
3. CVR・ACR … 取得できれば併記する

## 報告してほしい形

```
【前】9/04〜9/10  PV合計 ○○ / 日平均 ○○ / 予約数 ○件
【後】9/11〜9/17  PV合計 ○○ / 日平均 ○○ / 予約数 ○件
差分: PV ○○% / 予約 ○件

8月のベースライン: 週あたりPV ○○〜○○(最小〜最大)
→ 今回の差が、このブレ幅の中に収まっているか / 超えているか
```

**判断を書き添えること。** 「PVが◯%伸びた」だけでなく、**8月のブレ幅と比べて意味のある差
なのか**を必ず添える。7日×7日では偶然の差が出やすいので、断定しないこと。

日次の数値もそのまま残す(あとで再集計できるように)。

## 出力先
