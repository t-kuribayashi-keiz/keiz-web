### ⚠ CVR/ACRの定義(2026-09-24訂正。初版は逆に書いていた)

**この指示書の初版は CVR と ACR の意味を取り違えていた。** 実測時に画面のⓘから拾った
HPBの正しい定義は以下(`hpb-ribbon-kpi` の定義と一致する):

```
サロン情報PV ──CVR──> クーポン閲覧 ──ACR──> 予約完了
```

- **CVR** =(クーポンメニューPV + 紐付けクーポンクリック)÷ サロン情報PV … **興味**の段階
- **ACR** = 予約完了画面PV ÷(クーポンメニューPV + 紐付けクーポンクリック) … **予約**の段階

**「予約数 ÷ サロン情報PV」はHPBのCVRではない。** この値を使う場合は
**「予約率(算出)」**という別名で載せ、HPBのCVRと混同させないこと。

| 段階 | 指標 | 何が分かるか | 今回の位置づけ |
|---|---|---|---|
| 発見 | **サロン情報PV数・総PV数** | 掲載を見つけてもらえたか | 第1段階の伸びが維持されているか |
| 興味 | **CVR** | 見た人がクーポンを見にいったか | **第2段階(特集・クーポン)が直接効く段階** |
| 予約 | **ACR・予約数・予約売上高** | 実際に予約に至ったか | 最終成果。ただし母数が小さい |

**CVRが今回の要**。予約数は5院合計でも週10件前後しかなく6日では判定できないが、
CVRは予約より母数が大きいため、**6日間でも動きが見える可能性がある中間指標**。
特集・クーポンの改修が効いたかどうかは、まずここに出る。

### CVR・ACRの取得について(前回の取りこぼし)

前回取得した日次CSVの列は以下の5項目(自店/同P同A平均のペア)だけで、**CVRとACRが
入っていない**。

```
対象年月日, サロン情報PV数, 総PV数, 予約数, 予約売上高
```

一方、分析画面のサマリには **CVR・ACRのグラフが表示されている**(栗林さん提供の
スクリーンショットで確認済み)。つまりデータは存在するので、今回は次の手順で取ること。

1. サロンレポートの出力条件に **CVR・ACRを含められる形式がないか確認**する。
   あればそれを使って日次で取得する
2. 日次で取れない場合は、**分析画面のサマリから月次・週次の値を読み取って記録**する
   (グラフの数値、またはCSV出力・印刷から)
3. それでもACRが取れない場合は、**取れなかったことを明記して報告**する。
   勝手に別の指標で代用しないこと

**CVR・ACRとも、日次CSVの4項目からは計算できない。** どちらも分母に「クーポンメニューPV+
紐付けクーポンクリック」を含むが、この数値が日次データに無いため。画面から取得すること。

「予約数 ÷ サロン情報PV」は算出できるが、これは**HPBのCVRでもACRでもない別の指標**。
使う場合は「予約率(算出)」と明記する。

### 2026-09-24 実測で判明した制約(次回はここから始める)

- **区間比較できるのはPV・総PV・予約数・予約売上高の4つだけ。** 推移(日次)画面も
  CSVも、この4項目しか持っていない
- **CVR/ACRは「基本情報」画面にしかなく、対象月の1行のみ**(当月を選ぶと前日までの累計)。
  サロンレポートのダウンロードも月単位でしか選べない。**日次・週次では取れない**
- したがって「9/18〜23だけのCVR」は直接は取得できない

**回避策(次回はこれを使う)**: 基本情報の当月累計スナップショットを2つの日付で記録し、
差し引きでその間の値を算出する。

```
クーポン閲覧数 ≈ CVR × サロン情報PV
予約完了PV    ≈ ACR × クーポン閲覧数
```

9/23時点の累計は `hpb-ahaki-light-2026-monthly-basicinfo.csv` に保存済み。
**10/1に9月の確定値を取れば、9/24〜30(第2段階の反映後だけの7日間)のCVR/ACRが出せる。**
10月以降は週1回このスナップショットを取る運用にする。

## 判断にあたっての注意(重要)

**予約数で結論を出そうとしないこと。** 前回の測定では5院合計の週間予約数が9件→9件。
6日間・5院でも十数件の規模にしかならず、**数件の増減は偶然の範囲に収まる**。

したがって報告には必ず次を添えること:

- 8月のベースライン(週次の最小〜最大)と比べて、差がブレ幅を超えているか。
  **指標ごとに個別に判断する**(PVは超えていてもACRは超えていない、等があり得る)
- 超えていない場合は「**判定できない**」と明記する。伸びたように見えても断定しない
- 第1段階のPVの伸びが**維持されているか**(こちらは前回明確な差が出ているので、
  減っていないことの確認が重要)

### 3段階を組み合わせて読む

単独の指標ではなく、**どの段階で詰まっているか**を読む。

| パターン | 読み方 |
|---|---|
| PV維持 + CVR上昇 + 予約横ばい | 第2段階は効いている。予約化は母数の問題なので時間を置いて再測定 |
| PV維持 + CVR横ばい | 特集・クーポンが響いていない。中身(訴求・価格・見せ方)の見直しが要る |
| PV低下 | 第1段階の効果が剥がれている。掲載順位や競合の動きを確認する |
| PV維持 + CVR上昇 + ACR低下 | クーポンは見られているが予約直前で離脱。予約枠・料金・導線を疑う |

**PVの増減は必ず同P同A平均と並べて読む。** 自店だけ見て「下がった」と判断しない。
競合平均も同じだけ下がっていれば、それは市場側の動き(連休・季節要因)であって
施策の効果が剥がれたわけではない。

**第2段階の本当の評価は1ヶ月後**(10月中旬、月次リボンデータが出てから)。今回はあくまで
「悪化していないか」「方向として動いているか」を見るにとどめる。その旨も報告に書く。
