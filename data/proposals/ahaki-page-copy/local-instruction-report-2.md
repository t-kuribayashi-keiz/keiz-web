### 見る指標

1. **CVR(予約数 ÷ サロン情報PV)** … 第2段階が効くのはここ。**主指標**
2. **予約数・予約売上高** … 実数で併記
3. サロン情報PV・総PV … 第1段階の伸びが維持されているか(元に戻っていないか)の確認
4. 同P同A平均(競合平均) … 市場全体の動きと切り分けるための対照


## 判断にあたっての注意(重要)

**予約数で結論を出そうとしないこと。** 前回の測定では5院合計の週間予約数が9件→9件。
6日間・5院でも十数件の規模にしかならず、**数件の増減は偶然の範囲に収まる**。

したがって報告には必ず次を添えること:

- 8月のベースライン(週次の最小〜最大)と比べて、差がブレ幅を超えているか
- 超えていない場合は「**判定できない**」と明記する。伸びたように見えても断定しない
- 第1段階のPVの伸びが**維持されているか**(こちらは前回明確な差が出ているので、
  減っていないことの確認が重要)

**第2段階の本当の評価は1ヶ月後**(10月中旬、月次リボンデータが出てから)。今回はあくまで
「悪化していないか」「方向として動いているか」を見るにとどめる。その旨も報告に書く。
