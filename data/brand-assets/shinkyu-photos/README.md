# 鍼灸/美容鍼 実写素材(グループ共通)

2026-09-11、栗林さんが提供。**広告用の公式素材で、写っているクライアント・スタッフとも
HPB等の外部広告での使用に同意済み。特定の店舗専用ではなく、グループ共通でどの店舗の
ページに使ってもよい素材**とのこと。

あはき柔整プランページのブラッシュアップ([../../proposals/ahaki-page-copy/](../../proposals/ahaki-page-copy/))で、
AI生成画像の代わりに使う想定で追加した。AI生成では実際の制服・院内と食い違うリスクが
あったため、この実写素材の方が優先度が高い。

## フォルダ構成

- `美容鍼/`(11枚) — 顔への美容鍼施術。カウンセリング後の顔クローズアップ、鍼を刺す手元、
  顔全体に鍼が入った状態など。マロン(えんじ)色の制服袖が写り込んでいるカットが複数あり
- `鍼治療/`(19枚) — 肩・背中・腹部などへの全身鍼。施術者の手元クローズアップが中心。
  マロン色・ネイビー色、両方の制服袖が写っている(スタッフや店舗による違いの可能性)
- `お灸/`(2枚) — お灸(棒灸/温灸と思われる)の実施シーンと、色付きお灸素材の物撮り
- `その他/` — `妃優香先生鍼.JPG`(ファイル名から特定スタッフの施術シーンと思われる。
  スタッフ紹介に使う場合は本人の氏名・掲載可否を店舗に再確認すること)、`IMG_1902.JPG`・
  `IMG_1904.JPG`(全身鍼施術、院内の床・什器も一部写り込んでいる)

## 使い方の注意

- **院内全体を写した引きの写真は無い**(全て施術シーンのクローズアップ)。「当院のこだわり
  ③」のような院内全体を見せたい箇所には、この素材ではなく各店舗の既存フォトギャラリーに
  ある院内写真を使うこと
- **施術後の満足そうな笑顔・美肌の仕上がりを見せるカットも無い**。フォトギャラリーの
  「施術後の美肌イメージ」「笑顔のクライアント」枠は、この素材で埋まらない場合はAI生成の
  ままにするか、店舗側で該当写真があれば差し替える
- グループ共通素材のため、5院で同じ写真を使い回しても問題ない(HPBの複数の自社ページで
  同一カットが登場すること自体はSEO上のペナルティ等の対象ではない)
