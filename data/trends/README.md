## 取得条件(ここを外すと数字の意味が変わる)

- **月次のCSVであること。** Googleトレンドは指定期間が短いと**週次**で返す
  (2025/1〜2026/8の20か月では週次だった)。週を月に平均しても、トレンド自身の月次出力は
  再現できない(2026-09-03に検証: 最大誤差10〜13、完全一致は25%)。**桁は合うので目視では
  気づけない。** 期間を「過去5年」など長めにすると1列目が「月」になる。スクリプトは
  1列目の見出しが「月」でなければ停止する。
  期間を変えると正規化の基準(期間内の最大値=100)も変わり生の値は全部動くが、
  評価に使う正規化ブロック(2025/1整骨院=100)は基準を打ち消すので影響しない
- **5キーワードを1つの比較で同時に**取得する。1つずつ取ると、それぞれが自分の期間内最大値を
  100として正規化されるため、**キーワード間の比較ができなくなる**。数字は自然に見えるので
  気づけない。スクリプトは「100に達しているキーワードが3つ以上」なら別々取得とみなして停止する
- 地域=日本 / 期間=2025年1月1日〜対象月末 / カテゴリ=すべて / ウェブ検索
- URL: `https://trends.google.co.jp/trends/explore?date=2025-01-01%20<対象月末>&geo=JP&q=整骨院,整体,腰痛,肩こり,骨盤矯正&hl=ja`
  → 「時系列」カードの右上からCSVをダウンロード

## 毎月やること

**新しい月の行を足すのではなく、全期間を取り直して列ごと書き換える。**
Googleトレンドは指定期間内の最大値を100に正規化するため、期間が延びて新しい最大値が出ると
**過去の月の値もすべて再スケールされる**。1行だけ足すと、古い行と新しい行で基準がずれた表になる。
(2026-09-03 栗林さん確認: 現在の運用も毎月全期間を取り直している)

## ファイル名

`YYYY-MM.csv`(対象月)。例: `2026-08.csv`。過去のCSVも残しておくと、
どの時点でどう再スケールされたかを後から追える。

シートの既存値を、取得した週次CSVから再現できない。

  **整骨院 2022年6月**なのに対し、シートの最大値は**整体 2026年7月**。
  つまりシートは2025年以降の短い期間を基準にしており、その期間だとトレンドは週次でしか返さない
