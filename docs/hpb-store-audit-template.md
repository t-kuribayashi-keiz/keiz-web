# HPB個店 まるごと点検テンプレート

1店舗(1掲載)のHotPepper Beauty掲載を、**上から下まで漏れなく**確認して記録するための
テンプレート。数字だけでは「なぜ伸びないのか」が分からないときに、掲載側の実物を見て
仮説を潰す目的で使う。

- **ブランド非依存。** 直営・サンズミライ・グッド・スマイル等、HPBを使う全ブランドで使える
- **読み取り専用。** この点検では掲載内容を一切変更しない。変更が必要と判断したものは
  「変更候補」として記録だけして、別途 `hpb-salonboard-update` で実施する
- 実行には**ログイン済みChromeのあるローカルセッション**が必要(クラウド実行環境では不可)

## 0. 始める前に決めること

| 項目 | 内容 |
|---|---|
| 対象掲載 | 掲載名を正確に(同一店舗で複数掲載がある場合は取り違えに注意) |
| 比較対象 | **必ず1〜2掲載を決める。**同ブランドで数字が良い掲載を選ぶ。比較が無いと「多い/少ない」が判断できない |
| 対象期間 | 分析数値を取る月 |
| 何を疑っているか | 事前の仮説を1〜3個書いておく。点検後に「潰せた/残った」を明記する |

**同一店舗で2掲載ある場合**(あはき柔整プランとライトプラン等)は、**両方を別々に点検して
並べる**。片方だけ見ると店舗要因と掲載要因を切り分けられない。

## 2. クーポン(ここが最重要)

**一覧を上から順に、1件も飛ばさず記録する。**並び順そのものが結果を左右する。

| # | クーポン名 | 価格 | 画像 | タグ | 利用条件 | 掲載期限 |
|---|---|---|---|---|---|---|
| 1 | | | 有/無 | | | |
| 2 | | | | | | |

チェックすること:

- [ ] **総件数**(多すぎて選べなくなっていないか。比較対象と件数を並べる)
- [ ] **並び順**。売れ筋・主力が何番目にあるか。比較対象での主力の位置と比べる
- [ ] **画像の有無と中身**。画像なしのクーポンがどれだけあるか
- [ ] **価格帯の構成**。最安・最高・中心価格。比較対象および近隣競合と比べる
- [ ] **利用条件**(新規限定/既存限定/対象メニューの制限)。意図せず対象を狭めていないか
- [ ] **掲載期限切れ・期限間近**のものが残っていないか
- [ ] **既存様向けの無料枠**(口コミ投稿・カウンセリング等)が新規枠を圧迫していないか
- [ ] 比較対象にあって**この掲載に無いクーポン**、その逆

## 3. メニュー

- [ ] 件数、並び順、価格
- [ ] クーポンと整合しているか(クーポンで謳う施術がメニューに無い等)

## 4. 写真

- [ ] TOP画像(3枚)の内容
- [ ] フォトギャラリーの**枚数**とカテゴリ内訳
- [ ] 「雰囲気・メニューなど」枠の使われ方
- [ ] 最終更新日

## 5. スタッフ

- [ ] 掲載人数、顔写真の有無、紹介文の充実度
- [ ] 指名予約の可否設定
- [ ] 資格表記(鍼灸師等)がクーポン内容と整合しているか

## 6. ブログ

- [ ] 総本数、**最終投稿日**、直近3ヶ月の投稿頻度
- [ ] 写真ありの記事の割合
- [ ] 比較対象との本数差

## 7. 口コミ

**予約ボタンを押す直前に見られる材料。件数が少ない掲載では効きやすい。**

- [ ] 総件数、平均点、★5件数
- [ ] **最新の投稿日**(止まっていないか)
- [ ] **返信率**と返信の最終日
- [ ] 低評価(★3以下)の有無と内容
- [ ] 口コミ投稿を促す動き(口コミ投稿クーポン等)が回っているか

## 8. 予約枠(空き状況)

**掲載を見た人が実際に予約できる状態かを見る。HPB公開側の予約カレンダーで確認する。**

- [ ] 直近2週間の**曜日別・時間帯別の◎/×**
- [ ] **×が連続している時間帯**(昼休み等)とその長さ
- [ ] **休業日**の位置。土日が休業になっていないか
- [ ] 日曜・祝日の営業時間が平日と違わないか
- [ ] 受付の締切(当日予約の可否、何時間前まで)
- [ ] スタッフ指名時と指名なしで空きが変わるか
- [ ] **メニューによって空きが変わるか**(所要時間の長いメニューで枠が取れなくなっていないか)

**注意: 公開カレンダーで見えるのは「これからの枠」だけ。** 過去に予約が入らなかった期間の
枠状況は、SalonBoard側の予約枠設定・シフトで別途確認する。ここを混同しない。

- [ ] 上位に出ている競合の顔ぶれ

## 11. ファネルで詰まりを特定する

上の数値から、**どの段階で落ちているか**を1つに絞る。

```
サロン情報PV ──CVR──> クーポン閲覧 ──ACR──> 予約完了
   (発見)                  (興味)              (予約)
```

| 詰まっている段階 | 見分け方 | 主に疑うもの |
|---|---|---|
| 発見 | PVがエリア平均に対して低い | 掲載順位、サロン名・サブコピー、写真、エリア/ジャンル設定 |
| 興味 | PVはあるがCVRが低い | TOP画像、こだわり条件、クーポンの見せ方・並び順 |
| 予約 | クーポン閲覧はあるがACR・予約数が低い | クーポンの価格・内容、口コミ、予約枠、受付時間 |

**「予約数÷PV」はCVRでもACRでもない。**使う場合は「予約率(算出)」と明記する。

## 13. 報告の書き方

必ずこの3つに分けて書く。**混ぜない。**

1. **事実** — 画面で見たままを記録。件数・日付・順番・価格
2. **潰せた仮説** — 事前に立てた仮説のうち、事実によって否定できたもの。**否定できたことも成果**として明記する
3. **残った仮説と次の一手** — 何をすれば白黒つくかまで書く

やってはいけないこと:

- **掲載内容を変更しない。**変更候補は記録するだけ
- **実数が小さいときに断定しない。**月10件未満の予約規模では、1〜2件の差は誤差
- 見ていない項目を「問題なし」と書かない。**見ていないなら「未確認」と書く**
- 氏名・電話番号等の個人情報を報告に含めない
