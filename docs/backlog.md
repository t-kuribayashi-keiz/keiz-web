### 工程⑥ Googleトレンドの更新(AN〜AT列)

「年間計画・目標」タブの右端に、5キーワード(整骨院 / 整体 / 腰痛 / 肩こり / 骨盤矯正)の
Googleトレンドの月次値が入っている。AN=年月 / AO〜AS=各キーワード / AT=5キーワード平均。
さらに下に「2025/1整骨院で正規化」した第2ブロックがあり、こちらは第1ブロック×(100÷AO2025/1)で
機械的に導ける(2025/1: 90→100、整体 89→99、腰痛 35→39、肩こり 82→91、骨盤矯正 9→10 で検算済み)。

**Claudeはこの数字を自分で取得できない。**

- クラウド実行環境からは`trends.google.com`への通信が組織のプロキシで拒否される(2026-09-03に確認)
- Googleトレンドには無料の公式APIが無く、非公式エンドポイントはデータセンターIPからの
  アクセスを厳しく制限するため、GitHub Actionsからの取得は運用に乗せられる信頼性が無い
- **数字を推測で埋めることは絶対にしない。** それらしい値が入ると誰も気づかないまま
  KPIの傾向判断が狂う

したがって取得は人(またはローカルのChromeを持つセッション)がCSVをダウンロードし、
Claudeは**書き込みと検算**を担当する分担にする。ダウンロード条件:

- 5キーワードを**1つの比較で同時に**取得する(別々に取ると正規化の基準がバラバラになり、
  キーワード間の比較ができなくなる)
- 地域=日本 / 期間=2025年1月1日〜対象月末 / カテゴリ=すべて / ウェブ検索
- URL: `https://trends.google.co.jp/trends/explore?date=2025-01-01%20<対象月末>&geo=JP&q=整骨院,整体,腰痛,肩こり,骨盤矯正&hl=ja`

**設計上の注意(見落とすと過去の数字が静かに狂う)**: Googleトレンドは
**指定期間内の最大値を100として正規化する**。期間を延ばした結果どこかの月が新しい最大値に
なると、**過去の月の値もすべて再スケールされる**。したがって毎月やるべきは
「新しい行を1行足す」ではなく「**全期間を取り直して列ごと書き換える**」。
実際、現在の第1ブロックの最大値は整体2026/7=100。

未対応: (1) CSVを1つもらってフォーマットを確認する、(2) CSV→AO〜AS+AT+第2ブロックの
書き込み処理を実装する(①②⑤と同じく読み返し検算付き)、(3) 現在の運用が毎月全期間を
取り直しているかを栗林さんに確認する
