## 機械的に拾える所見

**合計と1店舗あたりで伸びの見え方が違う** (2026-03 → 2026-08): セッション合計は 11,208 → 12,418 (+11%) だが、1店舗あたりでは 467 → 497 (+6%)。店舗数が 24 → 25 に増えた影響を除くと、伸びはこの差のぶんだけ小さい。

**検索結果に出た回数が1店舗あたりで減り続けている**: 表示回数/店が 5,548 → 4,757 (-14%)。クリック数はCTRの改善(2.6% → 3.3%)で支えられているが、母数が縮み続ければいずれ効かなくなる。順位・表示回数を戻す施策と、CTR改善は別の打ち手として並行させること。

**Search Consoleのデータが取れていない店舗が11件(2026-08時点)**: FKDインターパーク店、サクラス戸塚店、下高井戸店、久我山店、戸越銀座店、水戸京成百貨店、浜田山店、祖師谷店、笹塚店、西新宿店、高円寺店。サービスアカウントへの権限付与待ちだった(GSCはサイト単位でしか付与できない)。**2026-09-07に栗林さんが残り店舗への個別付与を完了し、25店舗全てに到達済み**(詳細は`brands/relax/CLAUDE.md`「`relax-analytics.yml`実行結果」参照)。

**順位は取れているのにCTRが低い店舗**(平均10位以内 かつ CTR 5%未満): 
- たまプラーザ東急百貨店: 平均9.4位 / CTR 3.0%
- 方南町店: 平均9.3位 / CTR 3.1%
- イオン入間店: 平均9.4位 / CTR 3.7%
- 千歳烏山店: 平均8.6位 / CTR 4.5%

  順位を上げる施策ではなく、タイトル・ディスクリプションの見直しが先。
