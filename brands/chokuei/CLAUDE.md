# 直営 ブランドコンテキスト

このファイルはブランド「直営」専用の個別コンテキストです。ルートの
[CLAUDE.md](../../CLAUDE.md) に定義された全社共通ルール(組織構成・業務フロー・認証情報の
扱いなど)を前提とし、**このファイルの記述とルートCLAUDE.mdの記述が矛盾する場合は、常に
ルートCLAUDE.mdを優先する**。

直営は整骨院グループの中で院数・法人数・紐づく実務Skillの数がいずれも最大のブランドで、
運用の複雑さが最も高い。このファイルは
[docs/org-review-log.md](../../docs/org-review-log.md)(特に「2026-09-02 ブランド『直営』
134院・『心身堂』7院の追加」「2026-09-03」各エントリ)・`docs/backlog.md`・
`data/clinics.json`の該当エントリから実際に確認できた事実のみをまとめたもので、推測で
埋めた箇所はない。未確認の点は末尾の「未確認事項」に明記する。

## ブランド概要

- ブランド名: 直営
- 院数: **135院**(`data/clinics.json` の `brand: "直営"` と一致確認済み)
- 業態: 整骨院(`type: "seikotsuin"`)
- エリア: **全国広範**。千葉・東京・埼玉・神奈川を中心に、北海道・宮城・新潟・福島・
  茨城・長野・静岡・愛知・京都・大阪・兵庫・岡山・福岡・沖縄まで分布する。同じ関西圏でも
  「サンズミライ」(大阪・滋賀・和歌山・京都の関西圏限定)とはエリアが重ならない前提で
  はなく、直営も京都・大阪に院を持つが、法人体系(下記)が別系統であるため別ブランドとして
  扱っている

## 法人体系(8法人)

直営は単一法人ではなく、以下**8法人**にまたがる院がすべて「直営」ブランドに束ねられている
(`corporation` フィールドに法人名が入る):

- クラシオン
- エフアール
- ケイズ
- フォース
- ドリーム(ドリームジャパン。院マスタ上の`corporation`表記は「ドリーム」、メールドメインは
  `djapan.biz`)
- アポロ
- バーニング
- トラスト

過去のclaude.ai上の引き継ぎ書には「直営とサンズミライは統合可」という提案があったが、
実際の院マスタでは直営(135院、上記8法人)とサンズミライ(18院、法人ミライ/サンズ)は
別タブ・別法人体系・別エリア分布で管理されており、統合は見送られている
(詳細は[docs/org-review-log.md](../../docs/org-review-log.md) 2026-09-02
「院マスタの構造確認とブランド『サンズミライ』18院の追加」参照)。

## 店舗ID・ドメインの命名規則

- `data/clinics.json` の id は、各院の既存社内メールアドレスのローカル部をそのまま流用
  している(例: `motoyawata@keizgroup.jp` → `chokuei-motoyawata`)。メールアドレスは
  元々院ごとに一意な識別子として運用されていたため採用された
- ウェブサイトのドメインは複数系統が混在する: `*.chiryouin.biz`(サブドメイン形式が主流)、
  `chiryou-in.biz/<院名>/`(ハイフンあり、新しめの院に多い)、`curacion.jp/<院名>/`
  (クラシオン法人系)、`*.chiryou-in.biz`(ドリーム法人系、メールドメインも`djapan.biz`)
  など。ブランド全体で単一ドメイン基盤には統一されていない

## 紐づく実務Skill・自動化

直営には複数の実務Skill・自動化が既に紐づいており、ブランド単体としては最も運用の複雑さが
高い。

### 1. SalonBoardクーポン運用(`salonboard-operator`エージェント)

HotPepper Beauty SalonBoard(salonboard.com)のクーポン等の定型更新は、
[.claude/agents/salonboard-operator.md](../../.claude/agents/salonboard-operator.md)が
ブランド非依存で担当する。実運用例(2026-09-02)はスマイル(5院)・グッド(7院)向けの
口コミクーポン確認・新規作成・反映だったため、**直営の院がSalonBoard/HPB掲載の対象に
実際に含まれるか、`data/clinics.json`側ではまだ確定していない**(下記「未確認事項」参照)。
一方、KPI集計(下記3.)の「年間計画・目標」タブにはHPB店舗数(直営/サンズ/ミライ別)の
列があり、2026年8月時点でHPB直営121院分の広告費支出が確認されている(後述の広告費
シートより)。実額データが存在する以上、直営の相当数の院がHPB/SalonBoardの対象である
可能性は高いが、対象院の一覧としての確証はまだない。

### 2. CRM×HPB突合(`hpb-crm-reconciliation` Skill)

[.claude/skills/hpb-crm-reconciliation/](../../.claude/skills/hpb-crm-reconciliation/)は
CRMデータとHotPepper Beauty側のデータを突合するGASベースのSkill。2026-09-03の棚卸しで
対象院数の記述を`data/clinics.json`確定時点の実数(直営135・サンズミライ18・心身堂7・
スマイル11・グッド7・リラックス25・LUNA1、合計204)に更新したが、
**このツールが実際にどのブランドを対象にしているか(204院全体か、整骨院系ブランドのみか、
直営単体か)は依然未確認**。憶測で「直営のみ」等の決め打ちはしていない。

### 3. 月次KPI集計自動化(`functions/kpi-aggregation/`)

[functions/kpi-aggregation/CLAUDE.md](../../functions/kpi-aggregation/CLAUDE.md)は、
**直営+サンズミライを合算した**約149〜150店舗分の月次WEB集客KPI(HP・HPB・EPARK・
SEO/MEO/PPC等の集客数・UU数、店舗数)を、Sheets API + GitHub Actionsで自動集計・転記する
仕組み。単一ブランドに閉じないため`functions/`配下に置かれている(直営専用ではない)。

- 対象スプレッドシート: 「【2026年_月次報告】集客数」(所有者 `mar-yoshida@keizgroup.jp`)
- サービスアカウント: `chokuei-sunsumirai-kpi-writer@keizgroup-automation.iam.gserviceaccount.com`
  (書き込み権限あり。GCPプロジェクトは全社共通の`keizgroup-automation`)
- 2026-09-03時点で工程①②⑤⑥(集客数・UU数の転記、店舗数の転記、ダッシュボードAG〜AO
  への転記、Googleトレンドの集計)が本番稼働済み。工程③(PPC・META)は自動化保留の判断済み、
  ④(紹介・オフライン合計・AI)はヒアリング待ち
- **L列(店舗数)は当面手動運用**(2026-09-03、栗林さんの判断)。ダッシュボードの複数指標
  (AH・AK〜AO)の分母に効くため、速報値に更新する際は人がL列も見直す必要がある
- EPARK店舗数の法人名マッピングは`data/epark-corporations.json`に切り出されており、
  直営の8法人名(クラシオン/ケイズ/エフアール/フォース/ドリームジャパン/アポロ/
  バーニング/トラスト)がそのまま「直営」の括りに対応する
- 広告費シート上の店舗名マッチングは`scripts/store_matcher.py`が担当(冠文字・整骨院→整体院
  改名・針灸/鍼灸表記ゆれ等を吸収する緩いマッチング)
