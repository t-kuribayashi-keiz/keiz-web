# Org structure convention (as of Sept 2026)

This is the concrete model produced by the source session for keizgroup's acquisition/marketing function. Treat it as a *worked example* of the pattern, not a fixed template — axis names, people, and counts will drift; re-confirm with the user each time (see SKILL.md Procedure step 2).

## The 3-axis model

1. **法人担当 (entity owner)** — formerly called 法人軸. Holds revenue/number responsibility for one or more corporate entities, regardless of channel. Same role as マーケ責任者 (marketing lead) — these were confirmed to be one and the same role, not two separate boxes.
2. **チャネル担当 (channel owner)** — formerly called 集客軸. Holds revenue/number responsibility for one acquisition channel, regardless of entity. Exactly three channels in this model:
   - 検索（PPC広告含） — search: SEO/MEO/LLMO/PPC/CVR improvement. Framed with an extra mandate: "流入とCVRを切り離して考えるのではなく、流入〜予約まで踏まえた全体最適化を担う" (own the whole funnel from traffic to booking, not just traffic).
   - SNS（META広告含） — SNS posting and META ads run together under one owner, on the logic that a single consistent voice across organic SNS and paid META ads produces better synergy than splitting them.
   - 広告（媒体掲載含） — portal/media advertising (e.g. HotPepper Beauty portal placement), explicitly **excluding** PPC and META (those belong to the other two channel owners respectively) — this exclusion had to be called out multiple times/places because the plain label "広告" reads as if it could include PPC/META.
3. **スペシャリスト業務 (specialist)** — cross-channel domain expertise that all channel owners draw on; not tied to one channel or one entity. Domains: 制作・ディレクション (production/direction), 媒体設定・作業 (channel/tooling setup and operations, includes vendor-facing 窓口対応), AIシステム化 (AI/systems). Numbers/KPI responsibility stays with the channel owner; the specialist's role is execution support, decided in consultation with the relevant channel owner ("役割分担やマイクロKPIはチャネル担当と相談のうえ決める").

Deliberately **not** part of the ideal-structure diagram: any per-entity or per-corporation breakdown. The model is meant to apply identically regardless of which entity/corporation is in question — entity-specific assignment only shows up in the second "who's actually in which seat" section, never in the "ideal shape" section.

## Operating-policy language captured per axis (reusable phrasing pattern)

- **チャネル担当の運用方針**: できるだけ分析・施策立案に時間を使う。最大の課題はディレクション工数がかかっていること→対策として専門領域を実働できるパートさんを育てる。業者MTG後にパートさんへ噛み砕いて指示する二度手間を無くすため、パートさんをMTGに同席させ、その場で実行内容までまとめてそのまま実行してもらう、など。
- **スペシャリストの運用方針**: 各チャネルを横断して対応する。役割分担やマイクロKPIはチャネル担当と相談のうえ決める。パートさんとの関係構築の考え方はチャネル担当と同様。
- **法人担当（マーケ責任者）の運用方針**: 報告方法、スケジュールは別途整理予定（未確定のプレースホルダーとして明記しておいてよい — 無理に埋めない）。

One footnote worth preserving as a pattern (later removed from the final published version at the user's request, but useful context for future updates): ピラティス was flagged as "松井先生コンサルにて着手中" (in progress under an external consultant) rather than a flat evaluation mark — i.e. it's fine to annotate a cell with a short in-progress note instead of forcing it into ○/△/×.
