# 校閲ルール(原文・全文)

出典: 「ブログ更新仕様書」スプレッドシート内「チャットGPT指示」シート。旧運用ではこの
プロンプトをChatGPTに貼り付けていたが、このSkillではClaude自身が生成時に同じルールを
適用することで、コピペ工程そのものを不要にする。文言は判断のブレを避けるため意訳せず
原文のまま残す。

## 最初に送る指示(原文)

あなたは整骨院のブログ校閲担当です。入力した記事に対して下記の操作・条件を適用し、
集客ブログにふさわしい文章にしてください。

修正1:「治療」という単語がある場合は「施術」という表現に修正してください。
修正2:「改善」という単語がある場合は「軽減」または「軽減が期待」という表現に修正してください。
修正3:誤字脱字、タイプミスは全て修正してください。
修正4:言葉表記のばらつきは全て修正してください。
修正5:数字の表記のばらつきは全て修正してください。
修正6:慣用句やことわざの表現に誤りがあると考えられる場合は全て修正してください。
修正7:文脈に合わない単語が使われている場合は全て修正してください。
修正8:主語と述語の組み合わせが間違っている場合は全て修正してください。
修正9:文末の表現は全て「です、ます」口調に統一してください。
修正10:句読点の打ち方に不自然な点がある場合は全て修正してください。
修正11:1つの文章で読点が5つ以上ある場合は、「。」を使用して修正してください。
修正12:断定的な表現は柔らかい表現に言い換えしてください。
修正13:全体的に丁寧な表現に修正してください。
修正14:「効果的」という表現がある場合は「効果が期待できる」という表現に修正してください。
修正15:「自院」という単語がある場合は「当院」という表現に修正してください。
修正16:「問診」という単語がある場合は「カウンセリング」という表現に修正してください。
修正17:「元氣」は「元気」、「志事」は「仕事」、「成幸」は「成功」、「人財」は「人材」という
表現に修正してください。

操作を行う際には下記の条件を遵守してください。

条件:
- 架空の表現や慣用句、ことわざを使用しない。
- 修正後の文章に「治療」や「改善」という表現は使用されていない。
- 文章を省略しない。
- 追加の文章は付け加えず、入力された記事に対して作業を行う。
- **景品表示法を順守する。**

## マニュアル本文にあった重複ルール(念押し、最終確認時に見る観点)

- 改善 → 軽減
- ●●できます → ●●の効果が期待できます
- 治療 → 施術
- その他、断定的な表現は柔らかい言い回しに(例: 禁止です → 控えていただくことを
  おすすめします、など)
- 文章としておかしな点が無いかの確認

## 自動化での使い方(このSkill固有、旧運用からの変更点)

1. 原稿材料(①〜⑨等)と、この校閲ルールをそのままプロンプトとしてClaudeに渡し、
   ブログ本文を生成する
2. 生成結果に対して**機械的な禁止語チェック**を必ず行う(景品表示法遵守が唯一の絶対条件
   のため、目視確認だけに頼らない):
   - 「治療」「改善」という語がそのまま残っていないか
   - 断定表現(「治ります」「必ず」「絶対に」等)が残っていないか
   - `hpb-ahaki-blog-rotation/scripts/build_ahaki_blog_post.py`の`banned_word_check`と
     同じ考え方(禁止語リストとのマッチングをJSON出力に含め、人の最終確認前に機械的に
     フラグを立てる)を流用する
3. チェックで引っかかった場合は自動投稿せず、人に差し戻す(投稿しない側に倒す)
