# 特集 (`CNK/draft/specialList` / `specialEdit`)

Learned 2026-09-17 while rolling out 本八幡南口鍼灸接骨院(H000822241)の特集4件構成
(鍼灸施術を受けたい/首・肩のつらさを改善したい/メンズにオススメのサロン/お肌をきれいにしたい)
to the other 4 あはき柔整プラン salons (H000822239/H000822243/H000822244/H000822247).
Confirmed on all 5 salons.

## 横展開の前に、展開先の特集件数を確認する

「A院で確立した特集構成をB院にも」という依頼でも、**B院側には特集が1件しか登録されていない
ことがある**(2026-09-17: 4院とも「鍼灸施術を受けたい」1件のみ、しかも本八幡南口の1件目と
同一内容・同一日付2026/07/16 = 本八幡南口が4件構成になる前の共通初期状態)。
依頼が「画像設定」なのか「特集の新規追加+画像設定」なのかで作業範囲が変わるので、
`specialList`で件数を読んでから依頼者に確認する。

掲載可能件数は4院とも「最大3件」。プラン名表記が「Ｒあはき柔整」と「あはき柔整」で院により
異なっていた(影響は未確認)。

## 新規追加の手順

1. `specialList`の「新規追加する」→ 初回のみ「AI原稿作成サポート機能」の免責モーダル
   (「同意して編集する」)。同一ブラウザセッション内では再表示されないが、
   **claude-in-chrome拡張の再接続後は再び出る**。
2. `specialEdit`でジャンル→特集カテゴリ→特集詳細の3段セレクトを順に選ぶ。後段の選択肢は
   前段に依存して動的に変わるので、選択ごとに`wait`を挟む。
   - 鍼灸施術を受けたい: リラクゼーション / 鍼灸・接骨院
   - 首・肩のつらさを改善したい: リラクゼーション / 部位から探す
   - メンズにオススメのサロン: リラクゼーション / メンズ
   - お肌をきれいにしたい: エステ / フェイシャル
3. 写真: 「画像をアップロードする」プレースホルダーを1回クリックしても隠しinput(`#formFile`)が
   出ないことが体感5割前後ある。`document.querySelectorAll('input[type=file]').length`が0なら
   Escape→同じ座標を再クリック、を1〜2回。出たら`find`でref取得→`file_upload`。
   アップロード後の「画像アップロード」プレビューモーダルで**画像の中身をスクリーンショットで
   確認してから**「登録する」。
4. キャッチ(50文字)・コピー(100文字)。文字数カウンターは`.length`と一致しない(半角記号・数字は
   0.5カウントらしい)。確定済み文言を流用するなら上限超過の心配は無い。
5. フォーム内「登録」→ `specialList`に戻る。

## クーポン紐づけ(繰り返しハマった点)

- 「クーポン追加」モーダルは**1回に1件しか選べない**(別の行を選ぶと前の選択が外れる)。
  複数紐づけるなら「1件選ぶ→設定する→閉じる→再度クーポン追加」を件数分繰り返す。
- 行をクリックするとクーポン詳細が展開され、その描画中は`screenshot`が30秒タイムアウトする
  ことがある。フリーズではないので`wait`6秒程度→再`screenshot`。別操作を割り込ませない。
- **「設定する」直後の紐づけはページ内メモリ上だけで、サーバーに保存されていない。**
  この状態でタブを閉じる/`navigate`すると消える(1回これで作業し直し)。1件でも紐づけたら、
  次の操作の前に一覧下部の**「変更内容を登録する」**を押し、`specialList/doSort`への遷移と
  「並び替え/クーポン設定が完了しました。」を確認する。

## 掲載可能件数超過時の「非掲載にする」

ボタンがネイティブ`window.confirm()`を出し、CDP経由の全操作が30秒タイムアウトでブロックされる
(4院全店で再現)。`window.confirm = () => true`の事前セットは栗林さんの意向で使わず、
**タブが止まったら作業を止めてユーザーに手動でOKしてもらう**。OK後は`navigate`で再読込すれば
再開できる。

## 反映申請(特集掲載情報)

`reflectTop`の「特集掲載情報」行の反映申請 → `storeSpecialReflect/doRegister`に遷移し
「特集掲載情報の本番反映を予約しました。」が出れば成功(2026-09-17は5院ともAuto Modeで
ブロックされなかったが、ブロックされる場合もある — `menu-and-reflect-management.md`参照)。
公開サイトへの反映は実測**約15分**(8分後はまだ未反映、15分後に反映)。15分未満で見て
「反映されていない」と判断しないこと。
