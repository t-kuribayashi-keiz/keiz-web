# サロン基本情報 (`CNK/draft/salonEdit`) — field gotchas

Learned during the あはき柔整プランページ ブラッシュアップ作業 (5院, 2026-09-10/11)
— see `data/proposals/2026-09-10_あはき柔整プランページブラッシュアップ.md`.

## 「サロンの一言」と「サロントップ画像」は別の欄

見た目が近く、混同して誤って前者に画像を設定しようとした実例がある(その結果「横長は使えない」
という無関係なエラーに遭遇した)。画像アップロード系のエラーが出たら、まず設定先の欄が
「サロンの一言」(テキスト欄)ではなく「サロントップ画像」(画像欄)になっているか確認すること。

## サロントップ画像は3枚組で、横長画像も問題ない

メイン+サムネイル2枚の3枚組。「縦長専用」という制約は無い — 横長画像で問題なく登録できた
(上記の欄違いによる誤認が「縦長専用」という誤解を生んでいた)。

## サブコピーには文字数制限がある(150/150)

171文字の修正案は収まらず、139文字に短縮して登録した実例あり。コピーを書く際は事前に
文字数を見積もること。

## 「フリーワード」という名前のSEOキーワード専用欄は店舗によって見当たらないことがある

本八幡南口鍼灸接骨院ではそれらしい専用欄が見当たらず、近い候補は「備考」欄だった(未確認)。
この会社のアカウントでは「アクセス」「営業時間」欄の末尾に手動で`［キーワード/キーワード/…］`
という角括弧表記を付与している可能性がある。SEOキーワードの追加を頼まれたら、まず該当店舗の
実際の欄構成を確認してから作業すること。
