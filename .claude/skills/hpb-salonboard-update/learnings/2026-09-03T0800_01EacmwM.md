# 定休日・診療時間は data/clinics.json に入っていない(2026-09-03)

別セッションのsalonboard-operatorが「定休日を扱う仕組みがリポジトリのどこにも無い」と
回答した。**その回答は正しい。** ただし理由が紛らわしいので記録する。

栗林さんの認識では「診療時間などの情報は渡してある」。渡っているのは院マスタの
Googleスプレッドシートで、**そのファイル名が「診療時間」**(ID:
`1Pd2S6P9sAVMTk8FBqPJHKwihhggPgmvQk6pEFkgwHl8`)。2026-09-02にそこから
`data/clinics.json` へ取り込んだのは次の列だけ:

    id / name / brand / corporation / area / address / phone / website / email
    opened_at / status / type / acquisition_channels / notes

204院すべてこの構成で、**診療時間の列も定休日の列も入っていない**(全エントリの
キーを数えて確認済み)。ファイル名が「診療時間」なので取り込んだつもりになりやすい。

## いま定休日を知りたいときの参照先

- 院マスタ「診療時間」スプレッドシートの該当タブ(1タブ=1ブランド)
- 上記スプレッドシート内の「AIチェック用」シートには定休日列が既にあり、
  「木曜・日曜・第4木曜」形式のデータが入っている(別セッションが実機確認)

`data/clinics.json` を見て「無い」と判断するのは早い。マスタ側にはある。

## 対応中

`scripts/clinic_master.py --inspect` と `.github/workflows/clinic-master.yml` を追加した
(読み取りのみ)。列が確定したら `data/clinics.json` に `hours` と `closed_days` を足す。
それまでは定休日を前提にした判定を書かないこと。
