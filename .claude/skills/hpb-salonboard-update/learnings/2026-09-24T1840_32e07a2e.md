# HPBレポート(分析 → HOT PEPPER Beautyレポート)の読み取り手順と制約

2026-09-24、あはき柔整5院+ライトプラン5院の効果測定(読み取りのみ)で確認したこと。

## 取れるもの・取れないもの

- **推移** (`KLP/analysis/report/transition/`): 日次。指標は サロン情報PV数・総PV数・予約数・予約売上高
  の4つだけ(自店/同P同A平均)。**CVR・ACRは無い**
- **基本情報** (`KLP/analysis/report/basicInfo/`): CVR・ACR・クーポンメニューPV数・ブログPV数・
  フォトギャラリーPV数があるが、**対象年月単位の1行(月次)だけ**。当月を選ぶと前日までの累計になる。CSVも同じ1行
- **サロンレポート ダウンロード** (`CNK/mgr/clientReport/`): 集計対象月しか指定できない。日付範囲は不可
- → **日次・週次のCVR/ACRは画面上に存在しない。** 区間で比べたいときは、基本情報の当月累計を2つの日付で
  記録して差し引く(クーポン閲覧 ≈ CVR×サロン情報PV、予約完了画面PV ≈ ACR×クーポン閲覧)

## CVR/ACRの定義(ⓘツールチップ)

- CVR = (クーポンメニューPV数 + 紐付けクーポンクリック数) / サロン情報PV数 … 「興味」段階
- ACR = 予約完了画面PV数 / (クーポンメニューPV数 + 紐付けクーポンクリック数) … 「予約」段階
- 「ACR=興味の指標」と書かれた指示が来たら定義が逆なので指摘する

## 速く・確実に取る方法

- 両画面ともページ内スクリプトに `var graphData = JSON.parse("...")` があり、CSVと同じ値が入っている。
  推移は series 8本(PV自/平均、総PV自/平均、予約自/平均、売上自/平均。CSVの列順と同じ)、基本情報は20本
  (PV, CVR, ACR, 予約, 売上, 総PV, PV, ブログ, クーポン, フォト の各 自/平均)。
  `javascript_tool` で読めば**ダウンロード不要**
- 基本情報の前月へは `document.querySelector('.previousMonthBtn').click()` → 3秒待って再読み取り
- CSVボタンは `href="javascript:void(0)"` で、refクリック・JSの `.click()` ではダウンロードが始まらなかった。
  座標クリックなら1件目は保存されたが、**2件目以降はChromeが連続ダウンロードを保存しなかった**
  (確認ダイアログも出ない)。複数店舗を回すときはgraphDataの読み取りの方が確実
- 店舗の切り替えは `CNC/groupTop/` でIDのセルを完全一致で探してクリック。読み取りのたびに
  フッターのIDを確認し、違えばthrowしてbatchを止める
