# 女性鍼灸師 在籍チェック(shinkyu-staff-check)

HPBあはき柔整プランページの「雰囲気・メニューなど」①枠に**「女性鍼灸師在籍」バナー**を
出している。**在籍していない院にこの訴求を出し続けると虚偽表示になる**ため、毎月、
対象院の在籍状況を確認してこのバナーの出し下げを判断する。

## なぜブラウザで見るのか(重要・先に読む)

名簿「◇スタッフ写真一覧.xlsx」(Google Drive fileId `1v9TPAfbEh1tg0hEz9ha6-x637ww22hom`、
オーナー y-hirai@keizgroup.jp)には2つの厄介な性質がある。

1. **Driveのテキスト抽出では現行データが読めない。** 全員分の顔写真が貼られていて
   ファイルが非常に大きく、`read_file_content` は途中で切れて**古い版を返す**。
   2026-09-12の検証では、抽出できた約11万文字の中に同じ院が4箇所出てきたが、いずれも
   LG茂原に山﨑 政信・石井 一樹が在籍している旧構成だった(実際には両名とも異動済みで、
   現在のLG茂原の鍼灸師は佐々木 利恵子さん一人)。**抽出結果を信用しないこと。**
2. **性別欄が無い。** 列は氏名・社員番号・資格の3行のみ。ただし**顔写真は貼られている**ので、
   画面を見れば人の目では判別できる。氏名からの推測は絶対にしないこと。

この2つを同時に解決する唯一の方法が「ブラウザでシートを開いて、写真ごと目で見る」。
だから**このSkillはローカルPCのChrome(claude-in-chrome)が必須**で、クラウド実行環境では
動かない。以前は栗林さんに毎回スクリーンショットを送ってもらっていたが、その手間を
なくすためにSkill化した。**栗林さんにスクショを依頼しないこと。**

## 資格表記の読み方

栗林さん確認済み(2026-09-12):

- `鍼灸師` … 鍼灸師免許 → **カウントする**
- `柔整・鍼灸` … **柔道整復師と鍼灸師の両方の免許を持っている** → **カウントする**
- `灸` … きゅう師のみで鍼師免許を含まない可能性がある → **カウントしない**
- `鍼灸・マ` … 鍼灸+あん摩マッサージ指圧。鍼灸を含むので**カウントする**
- `柔道整復師` … カウントしない

シート上では資格セルが色分けされている(`柔整・鍼灸`=ピンク、`鍼灸師`=グリーン)ので、
色も手がかりになる。

## 手順

### 1. シートを開く

ブラウザで以下を開く。栗林さんはログイン済みのはず。

```
https://docs.google.com/spreadsheets/d/1v9TPAfbEh1tg0hEz9ha6-x637ww22hom/edit
```

閲覧のみモードで開くが、読むだけなので問題ない。**シートを編集しないこと。**

### 2. 5院それぞれのブロックを探す

シートは院ごとに**4行1組**の繰り返し構造になっている。

```
行1: 院名(A列) + 顔写真が横に並ぶ
行2: 氏名
行3: 社員番号
行4: 資格
```

院数が多く縦に長いので、**シート内検索(Ctrl+F / Cmd+F)で院名を入力して飛ぶ**のが速い。
`八幡宿` で検索すると東口と西口の両方がヒットするので、A列の表示を見て**西口**の
ブロックであることを必ず確認する。

### 3. 各院で読み取る

**列位置で氏名と資格が対応している。** 空列があるので、目視で真上・真下を辿って
正しく対応させること(テキストに起こしてから数えると空セルの分だけズレる)。

各院について次を記録する:

- 鍼灸有資格者(`鍼灸師` / `柔整・鍼灸` / `鍼灸・マ`)の氏名
- その人の**顔写真を見て、女性かどうか**
- 写真から判断が付かない場合は「**要確認**」とし、勝手に断定しない

`C.` で始まる名前はカウンセラー/受付で、資格欄は空。鍼灸の判定対象外。

### 4. `data/staff-shinkyu-roster.md` を更新する

現況表を今回の読み取り結果で置き換え、確認日を書く。

### 5. 判断して報告する

| 状況 | やること |
|---|---|
| 女性鍼灸有資格者が居る | その院は①枠バナーを出したままでよい。報告不要 |
| **前月は居たが今月居なくなった** | **その院の①枠バナーを取り下げる**よう salonboard-operator に依頼する。最優先で報告 |
| 新しく居るようになった | ①枠バナーを出せるようになった旨を報告(新規作成の指示は `data/proposals/ahaki-page-copy/ChatGPT向け_画像作成指示.md` の作業5①) |
| 写真から性別が判断できない | その氏名を挙げて栗林さんに確認を依頼する |

**何も変化が無ければ、リポジトリを変更せず「変更なし」とだけ報告する。** 毎月同じ内容を
報告しない。
