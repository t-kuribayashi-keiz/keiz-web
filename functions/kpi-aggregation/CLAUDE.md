## 数字の性質(重要)

同じ月の数字に**3つの段階**がある。取り違えると分析が壊れる:

| 段階 | 内容 |
|---|---|
| **中間値** | 月の途中(例: 8/16)時点の累計を日割りで逆算した**見込み**。月内の進捗把握用 |
| **速報値** | 月が終わって全データが揃った時点の数字。KPIの判断に使う |
| **確定値** | 速報値からさらに確定した数字。シート上に「速報値➤確定値で+0.3」等の補正メモがある |

**ダッシュボードに中間値が入ったまま月をまたぐと、未達に見える。** 月初に速報値へ更新する
のがこの集計作業の目的。

## 月次の更新手順(6工程)

栗林さんが毎月手作業で行っている流れ。①②⑤が自動化の対象。

| # | 内容 | 自動化 |
|---|---|---|
| ① | 「◯月HP(速報値)」「◯月HPB (速報値)」「◯月Epark(速報値)」各タブの合計集客数を「年間計画・目標」タブの該当月の行に転記。あわせてAB・AC・AE列のUU数を「◯月HP(速報値)」タブの合計から転記 | **対象** |
| ② | 同じ行のL〜O、Q〜S列に店舗数を記入(HP=速報値タブ / HPB=広告費シート / EPARK=専用シート) | **対象** |
| ③ | V・W列のPPC広告・META広告の集客数 | **保留**(現在チャットでやり取りして手入力。2026-09-02時点で自動化しない判断) |
| ④ | F列の紹介、J列のオフライン合計、X列のAIを別シートから転記 | 未着手(転記方法を別途ヒアリング) |
| ⑤ | 揃った1店舗当たりの数字(自動計算される行)を「2026年Web集客KPI管理ダッシュボード」タブのAG〜AO列へ転記。**AK列のSEO集客数は SEO+MEO+AI の合算値** | **対象** |
| ⑥ | Googleトレンドの集計 | 未着手(方法を別途ヒアリング) |

①〜④が揃うと、対象月の行から1店舗当たりの集客数が自動計算され、それをKPIとして使う。

## 実装方式: Google Apps Script

**サービスアカウント+Sheets APIではなくGASを使う。** 理由:

- この集計は**書き込み**を伴うが、既存のサービスアカウント(`smile-good-reporter`,
  `ad-spend-reporter`)はいずれも閲覧専用で、対象シートも違う
- このシートの所有者は`mar-yoshida@keizgroup.jp`。サービスアカウント方式だと編集権限の
  付与依頼が必要になる
- サービスアカウントの鍵はローカルPCにしかないため、クラウドから無人実行できない
- GASならスプレッドシート内部で所有者/編集者の権限で動く。**鍵も共有設定の変更も不要**
- ケイズグループは既にGASで3業務(CRM突合・シフト自動化・Driveフォルダ管理)を運用しており、
  貼り付け・実行の型がある
